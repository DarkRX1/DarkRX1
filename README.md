## Currently Building

### RXScan — Raw Excess Scan

Fast, bounded reconnaissance in Rust.

RXScan is a native reconnaissance scanner I'm building around a simple idea:
collect useful evidence, stay within explicit bounds, and don't claim more than the evidence proves.

Current work includes:

- Native TCP and UDP discovery
- Port-independent service identification
- HTTP, TLS, and DNS intelligence
- Evidence-driven findings
- Scope and execution controls
- Resume, diff, analysis, and reporting
- Performance-focused native Rust architecture

**Project:** [DarkRX1/RXScan](https://github.com/DarkRX1/RXScan)
